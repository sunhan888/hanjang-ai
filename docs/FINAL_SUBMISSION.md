# 한장해결AI 최종 제출 요약

## 한 줄 소개

주정차위반 과태료 사전통지서를 사진 한 장으로 읽어 고령자에게 마감일, 낼 금액, 다음 할 일을 쉬운 말로 알려 주는 모바일 웹입니다.

## 핵심 처리 흐름

1. 사진을 업로드합니다.
2. GPT-4.1이 고지서의 12개 항목을 읽습니다.
3. 코드가 날짜 순서, 금액, 계좌번호, 형식과 재확인 필요 여부를 검증합니다.
4. 검증 결과에 법령 근거를 붙입니다.
5. Agent가 상황별 할 일을 쉬운 문장으로 정리합니다.

## 최종 평가 수치

| 항목 | 결과 |
| --- | --- |
| 평가 대상 | 합성 고지서 20장 |
| 모델 | OpenAI GPT-4.1 |
| 과업 성공 | 20/20 (100%) |
| 핵심 3항목 조용한 오답 | 0/60 |
| 과잉 경고 | 0% |
| 처리 시간 중앙값 | 3.3~3.9초 |
| 백엔드 테스트 | 26 passed |

핵심 3항목은 감경과태료, 의견진술기한, 가상계좌입니다. 증거번호의 인쇄 라벨을 제거하는 규칙을 추가한 뒤에도 최종 평가 수치는 유지됐습니다.

## 추가 검증

- 실제 고지서 3장을 별도로 평가했습니다.
- 실물 결과는 모자이크와 표기 차이의 영향을 받아 참고용으로 기록했습니다.
- 법령 근거 7건을 국가법령정보센터 원문과 대조했고 모두 `verified: true`입니다.
- Agent 문장 다듬기에는 날짜·금액·계좌번호가 바뀌면 원문으로 되돌리는 숫자 보호 가드가 있습니다.
- 모바일 390×844 기준 정상, 확인 필요, 오늘 마감, 기한 지남, 법령, 할 일 자세히, 오류 화면 E2E를 통과했습니다.

## 시연 순서

1. 홈에서 고지서 사진을 선택합니다.
2. 사진 확인 후 판독을 시작합니다.
3. 결과 화면에서 마감일과 낼 금액을 보여 줍니다.
4. `이렇게 하시면 돼요`에서 확인, 납부, 의견 제출 순서를 보여 줍니다.
5. `내는 방법 보기`에서 계좌 복사와 납부 방법을 보여 줍니다.
6. `왜 그런지 법에서 확인하기`에서 법령 근거를 보여 줍니다.
7. 확인 필요·기한 지남 화면을 추가 상황으로 보여 줍니다.

## 한계와 안전장치

- 사진이 흐리거나 잘리면 억지로 추정하지 않고 확인 필요 또는 다시 촬영을 안내합니다.
- 숫자를 다듬는 과정에서 날짜·금액·계좌번호가 바뀌면 다듬은 문장을 사용하지 않습니다.
- 결과는 24시간 뒤 삭제되며, 서비스는 법률 자문이 아닙니다.
- 시연에는 합성 견본과 개인정보를 가린 실물만 사용합니다.

## 제출 전 공동 확인

- [ ] B 담당 배포본에서 HTTPS E2E 확인
- [ ] 실제 휴대폰에서 카메라·앨범·복사·공유 확인
- [ ] 고령자 사용성 테스트 3명 기록
- [ ] 시연 영상 및 발표 자료에 위 평가 수치 반영
- [ ] API 키·실물 개인정보·`capture/` 자료가 커밋되지 않았는지 확인
